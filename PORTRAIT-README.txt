PORTRAIT REPLACEMENT NOTES

This package currently uses an original, self-contained vector placeholder character so it can be previewed before you upload your photo. It is not a portrait of you.

When you upload a clear photo, create two transparent PNGs named id.png and right_pointing.png as described in the supplied GitHub Profile Playbook PDF. To embed your final images into the SVG assets, convert each PNG to a base64 data URI and replace the vector placeholder group in hero.svg and id-dashboard.svg with the embedded id.png; replace the placeholder group in connect.svg with right_pointing.png. Keep the image data inline to preserve the no-external-requests requirement. The README can remain unchanged.

The profile metrics are a dated public-profile snapshot and should be refreshed before publishing. No unverified project performance claims or unsupported awards have been included.
