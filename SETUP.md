# Publish your GitHub profile README

1. Open https://github.com/the-sparsh-shukla/the-sparsh-shukla.
2. Choose **Add file → Upload files**.
3. Upload `README.md` and the complete `assets/` folder, preserving the folder structure.
4. Commit with a message such as `Create animated profile README`.
5. Visit https://github.com/the-sparsh-shukla and check all sections.

The animated developer character is a generic vector illustration, not a personal portrait. The README avoids hard-coded live statistics. GitHub may render SVG animation differently from a browser.
