# Publish your GitHub profile README

1. Open your profile repository: https://github.com/the-sparsh-shukla/the-sparsh-shukla
2. Upload `README.md` and the entire `assets/` folder. Keep the five SVG files inside `assets/`.
3. Commit the changes to the repository's default branch.
4. Visit https://github.com/the-sparsh-shukla and check the images and links.

## Character and animation
The profile artwork uses an original animated vector character drawn directly in the SVG files. It does not use a personal photograph or require extra image files. Animations use CSS and include reduced-motion fallbacks; GitHub or other viewers may display some SVG animation differently.

## Project links
The four project names and repository URLs are listed in `README.md`; check them before publishing if you have renamed any repositories.
